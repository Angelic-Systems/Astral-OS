# Astral-OS

IMPORTANT! Astral-OS is a work in progress and is not yet ready for daily use! 

Astral OS is built for terminal power users. It uses a custom built compositor to render a full screen terminal emulator running the Zellij multiplexer to provide a tiling WM like expereance that doesn't break your flow.
